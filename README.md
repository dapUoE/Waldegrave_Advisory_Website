# Waldegrave Advisory LTD Website

A professional static website for Waldegrave Advisory LTD, a financial risk management consultancy specializing in FX, commodities, and cryptocurrency markets.

## Overview

This website is built with HTML, CSS, and JavaScript to showcase Waldegrave Advisory's services and expertise in financial risk management. The design is sleek, professional, and features interactive charts to visualize market data.

## Features

- Responsive design that works on all devices
- Interactive market charts using Chart.js
- Dark mode toggle for user preference
- Animated UI elements for modern feel
- Contact form (frontend only)
- Interactive market insights dashboard

## Pages/Sections

- Home: Introduction and key value proposition
- About Us: Company overview and values
- Services: Detailed service offerings
- Market Insights: Interactive data visualization
- Contact: Contact form and company details

## Technologies Used

- HTML5
- CSS3 (with custom variables and animations)
- JavaScript (ES6)
- Chart.js for data visualization
- Font Awesome for icons

## Setup

Simply open index.html in a web browser to view the website. No server or build process is required.

## Customization

- Update the content in index.html to reflect actual company information
- Modify chart data in main.js to display real market data
- Replace placeholder contact information with actual details
- Add additional pages or sections as needed

## Design Elements

- Professional color scheme with blue and gold accents
- Modern glass morphism UI elements
- Animated accents and transitions
- Dark mode support
- Responsive layout for all screen sizes
